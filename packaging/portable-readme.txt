Y-TEC Tsumugi Drive 1.0.0-internal-beta 公開前検証候補
=====================================================

このパッケージは正式リリース前の候補です。全製品経路、正式OS VM、代表実機、
配布物監査が完了するまで、重要データや業務端末に使用しないでください。
本製品は会社・勤務先の社内ソフトではなく、Y-TEC名義で個人開発・公開する
オープンソースソフトウェアです。

このパッケージに含むもの:
  - Y-TECが作成したWindows x64実行ファイル
  - 説明文書
  - Apache License 2.0の製品LICENSE／NOTICE
  - 第三者通知とSPDX SBOM
  - SHA-256一覧

このパッケージに含まないもの:
  - Microsoft Windows PE、WIM、ISO、CAB
  - Windows ADK／WinPE Add-on本体
  - Microsoft製EXE／DLLの再配布物

Windows版:
  ytec-tsumugi-drive.exe

正式版の操作モデル:
  - Windows版は、その場でコピー元とコピー先を選んで直接クローンします。
  - PE版は、PE上だけでクローン、イメージ作成・復元、起動修復を完結します。
  - 正式イメージ形式は単一ファイル.tsumugi v1です。
  - 全破壊操作は対象要約と大文字「OK」を要求します。
  - 予約ジョブ、固定名自動検索、自動実行、結果取込みは使用しません。

レスキューISO／USB:
  - 製品ZIPへADK／WinPEを同梱しません。
  - この開発候補ではADKの自動取得・自動導入はまだ接続していません。
  - 不足時は画面の導入ガイドに従い、Microsoft公式ADK 10.1.26100.2454、
    同版WinPE Add-on、必須更新KB5101684を利用者が先に導入します。
  - 署名、版、SHA-256、必須更新を検証したローカルADKから媒体を作成します。
  - USBは8GiB以上、16GiB推奨です。
  - 既定では4GiB FAT32起動領域と残容量のNTFSデータ領域を作ります。

現在の開発候補には、共通安全基盤と一部の直接操作入口が実装されていますが、
通常／縮小／MBR→GPTの全組合せ、.tsumugiの物理Adapter、ADK自動導入、救出、
全UI／VM回帰は未完了です。ビルド成功や過去形式のVM成功だけで、正式版の
利用可能性を表明しません。

この開発候補の「ドライブをクローン」画面では、縮小移行の直接クローンは
「準備中（書き込みません）」です。縮小 .tsumugi の作成／復元とは別の導線です。

設定とログは実行ファイル隣のdataだけへ保存する方針です。書込み不能な配置では
読取り専用診断だけを許可します。AppDataへ自動退避しません。
更新時は、初回安全ガイドの確認状態を含むdataフォルダー全体を残してください。

UAC、Secure Boot、Microsoft署名検査、BitLocker保護を無効化・回避しないでください。
詳しい手順、安全上の注意、通信の有無は同梱文書を確認してください。
