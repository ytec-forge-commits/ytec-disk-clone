## 実装中の修正

コピー/復元/MBR2GPTだけが使う `BcdBootStorePolicy::rebuild_fresh` を、単なる`/c`指定から次のトランザクションへ強化中。

1. Microsoft署名済みBCDBootを対象変更前に検証
2. 対象システム領域の固定BCDパスだけを通常ファイル/reparseなしで検査
3. 既存BCDを非上書きの固定退避名へ移動
4. 署名を再検証し、`BCDBoot /c`を実行
5. 新規BCD通常ファイルを確認
6. 成功時は退避を削除、失敗時は部分BCDを除いて旧BCDを復元
7. 単独起動修復の`preserve_existing`は変更しない

変更中ファイル:

- `src/BootRepair/include/ytec/bootrepair/bcdboot.h`
- `src/BootRepair/src/bcdboot.cpp`
- `tests/Unit/boot_repair_tests.cpp`

追加済みテスト観点:

- UEFI/BIOSのBCD固定パス
- 旧BCD退避、新規BCD確認、退避削除
- BCDBoot失敗時の旧BCD復元
- 成功終了でも新規BCDがない場合の失敗と復元
- 退避残留時に実行前停止

直前の単体ビルドは、通常PowerShellから直接`cmake --build`したためWindows SDKの`INCLUDE`が入らず`Windows.h`不在で停止した。コード不合格とはまだ判定していない。次は必ず同じPowerShellプロセスで:

```powershell
. .\scripts\Enter-MsvcEnvironment.ps1
cmake --build --preset msvc-x64 --target ytec-boot-repair-tests
.\out\build\msvc-x64\tests\ytec-boot-repair-tests.exe
```
