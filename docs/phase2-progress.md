# Phase 2 イメージ保存・復元進捗（2026-07-31）

> **履歴資料:** v2再設計前の旧イメージ形式／予約ジョブの証跡です。1.0.0の
> 現行形式は`.tsumugi` v1で、以下を製品操作として案内しません。

## 実装済み

- `.dcimg` v1固定256バイトヘッダー、正規セクション順序、64bit範囲検査
- Zstandardプロファイル1/非圧縮/ゼロチャンク、80バイト索引、独立SHA-256表、全体フッター
- Windows CNG SHA-256によるマニフェスト、各チャンク、ハッシュ表、全体検証
- 最大32MiBの読取りCallbackだけを使うWindows CNGインクリメンタルSHA-256
- 読取り専用コピー元をチャンクごとに1回読み、16/32MiB以下をZstandard level 3で圧縮し、小さくならない場合は非圧縮へ戻して抽象ステージング先へ書くv1ストリーム
- 公式Zstandard v1.5.7の静的ライブラリだけをBSD-3-Clause条件で使用し、辞書、legacy decoder、連結/末尾フレーム、内容サイズ不明/不一致を拒否するプロファイル
- 全索引、独立ハッシュ表、全非ゼロチャンク、フッター、全体SHA-256をステージング先から再読込みし、成功後だけcommitする確定境界
- begin/write/read/flush/hash/footer/commitの失敗時に未完了abortを要求し、abort失敗も成功扱いしない境界
- ローカルドライブ上の絶対`.dcimg`だけを許し、UNC、ADS、reparse経路、既存完成ファイル、既存`.partial`を開始前に拒否するWindows保存先境界
- 保存先ボリュームを物理ディスクへ対応付け、開始時と確定前に再列挙した安定識別でコピー元/指定コピー先との同一性を拒否する処理
- 作成予定長以上の空き容量、保護DACL、`CREATE_NEW`、全長予約、write-through、読戻し、flush、非上書き確定を行うWindowsファイルBackend
- 作成失敗後に所有権を得た`.partial`だけを破棄し、開始前から存在したファイルを削除しないRAII後始末
- 未知版、未知フラグ、未知圧縮、予約領域、切詰め、末尾追加、重複、範囲外、1ビット破損の拒否
- MBR先頭1セクター、GPT先頭/末尾領域を保持する正規パーティション表スナップショット
- 全イメージ検証後にだけ開始する合成復元
- 復元先の安定識別、非システム、容量、論理セクター、二段階確認
- パーティション表を先に無効化し、全データの書込み/読戻し/flush後に最後に確定する順序
- GPTでは末尾側を先、主側を最後に確定する失敗時境界
- 大容量イメージを全量メモリ展開せず、Readerで全体を完全検証後、
  非ゼロチャンクだけを最大32MiB保持し、必要なら有界展開して復元直前にSHA-256を再検証する
  ストリーミング復元境界
- Readerの例外、短い読取り、完全検証中キャンセルを0書込みで拒否し、
  完全検証後に変化したチャンクも主パーティション表確定前に拒否する境界
- 固定192バイトヘッダーと80バイト区画記録を持つ正規バイナリ
  バックアップマニフェスト
- コピー元安定識別、Windows版/AMD64、BitLocker完全復号、圧縮、
  GPT/MBR、起動方式、全区画の役割/範囲/ファイルシステム/クラスタを
  厳格に検証する意味ゲート
- MBRは先頭セクター、GPTは保護MBR/主副ヘッダー/主副エントリ配列だけを
  読み取り専用の実コピー元から取得するパーティション表キャプチャ
- 復元前のマニフェスト/コンテナ/パーティション表照合と、
  全データチャンクが宣言済み非MSR区画内にあることの確認
- 大容量ファイルを全件メモリ展開せず、ヘッダー/索引/フッター/
  メタデータだけを有界読取りし、全体/全チャンクSHA-256を最大4 MiB単位で
  完全検証するWindows復元プリフライト
- ローカル通常`.dcimg`、非reparse、読取り専用オープン、検証中キャンセル、
  検証後も復元実行無効を固定したWindows GUI入口
- 列挙済み情報だけで復元先候補の安定識別、元ディスク/システムディスク、
  読取り専用/リムーバブル/不明状態、形式、容量、論理セクターを確認し、
  合格しても復元実行無効を固定するWindows GUI候補欄
- 復元先情報と対象固有語の二段階確認後、ハッシュ付き復元予約ジョブだけを
  新規保存・全バイト読戻し検証するWindows GUI入口
- WinPEジョブ読込時に共通検証器で`.dcimg`全体、全チャンク、メタデータ、
  復元領域を再検証し、復元先容量、論理セクター、元ディスクとの分離を
  ディスク書込み前に確認する読取り専用プリフライト
- WinPE復元の実行直前条件を合格/危険/不明で扱い、BitLocker完全復号、
  既知LDM型、Storage Spaces、対応ファイルシステム、AC電源を必須、
  再起動保留を警告として評価する純粋なfail-closedモデルと製品検査器
- 必須条件が全合格でも物理復元を有効化せず、
  `requiredChecksPassed`と`executionEnabled=false`を分離したJSON/テキスト出力
- WinPEでドライブ文字だけが変わった場合、固定/リムーバブル媒体の同じ
  相対パスを最大23候補に限定し、各`.dcimg`の完全検証とジョブ指紋一致後だけ
  採用する`--search-image`自動再解決（再帰探索なし）

## 自動テスト

SHA-256既知ベクトル、Zstandard/非圧縮/ゼロチャンク往復、圧縮破損、末尾追加、長さ不一致、非圧縮fallback、各破損/境界入力に加え、スナップショット往復/破損、正規マニフェスト往復/非正規/意味矛盾、正常なMBR復元、破損イメージ0書込み、確認不一致0書込み、容量不足0書込み、データ/パーティション表重複0書込み、読戻し失敗時の未確定を合成メモリだけで確認します。さらに、圧縮/非圧縮ストリームが各コピー元チャンクを1回だけ読み、対応するメモリ作成結果とバイト一致すること、コピー元/再読込み/commit失敗時のabort、abort失敗の非隠蔽、短いSHA読取り拒否、MBR/GPT表の実キャプチャ、有界Readerの全件検証、検証中差替え、キャンセル、Windows通常ファイル入力、復元先候補の正常/元ディスク/システム/容量/セクター/不明/リムーバブル/列挙診断をモック/合成ファイルで確認します。有界Reader復元について、正常完走、読取り上限、最終MBR commit、完全検証後のチャンク変化、Callback例外、完全検証中キャンセルもモック確認済みです。復元予約ジョブの生成/確認不一致/システムディスク拒否と、WinPEでイメージ検証失敗または検証サービス不在時にディスク列挙前で停止する順序もモック確認済みです。
