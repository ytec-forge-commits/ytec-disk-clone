# WinPEネイティブGUI v2進捗

更新日: 2026-08-10

WinPE版はWindows版から独立し、起動後の初期画面から直接操作する。Windows側で
事前準備したファイルを必須にせず、コピー元、コピー先、イメージ、修復対象をPE上で
改めて選択する。

> 現在は直接クローン入口と共通安全基盤の接続中である。クローン、イメージ、
> 修復、救出をPEだけで完結する正式版フローは未完成である。

## 正式版の初期メニュー

- ドライブをクローン
- イメージを作成
- イメージを復元
- 起動を修復
- 救出モード
- ディスク診断

固定名ファイルの検索、予約一覧、自動プリフライト、自動実行、結果ログ取込みは
提供しない。

## 接続済みの基盤

- 静的MSVC x64のネイティブCLI／GUI
- LINE Seed JP、Tsumugiの三本糸配色、左ナビ、共通進捗表示
- 全ディスクの読取り専用列挙、安定識別、パーティション一覧
- PE上でコピー元・コピー先を直接選択するクローン入口
- コピー元のOSレベルread-only化と同一ハンドル保持
- 対象要約、大文字`OK`、実行直前再識別
- GPT／MBR CloneCore、bounded I/O、flush・読戻し、最終commit
- 起動最終化のBCDBoot新規BCDトランザクション
- 対象ディスク内のWindows／ESP／Active／UEFI・BIOS／WinRE読取り専用検出
- 1つのWindowsと1つの既存ESPが一意なGPT／UEFIと、既存MBR／BIOSの直接起動修復
- EFI所有権の読取り専用検査、実行直前再検査、第三者／未知EFIの開始拒否
- `.tsumugi`共通形式、作成・検証・復元計画、復元トランザクション
- 通常（exact）のディスク全体復元と、既存パーティション／未割当領域への個別復元
- 個別復元の範囲・対象選択、既存区画／entry保持、未割当への新規1entry確定、選択変更時の確認破棄
- Windows区画の個別復元後に、別画面・別確認で行う任意起動修復の案内
- 読取り／書込み／検証済み量、速度、経過・残り時間、取消可否の表示モデル

## 接続中・未完了

### 直接クローン

- 通常／縮小、MBR維持／MBR→GPT、パーティション選択
- Windows必須領域の自動選択
- 余剰容量の比例配分／未割当
- RAW以外の既存基本ディスクを確認後に自動消去・再構成
- USBメモリと起動中レスキューUSB全体の候補除外
- 成功したシステム対象のoffline保持と「検証完了・換装待ち」表示

### イメージ

- PE read-only epochへ結び付いた`.tsumugi` Source Provider
- NTFS／exFAT保存先と、レスキューUSBデータ領域の選択
- 完全／高速検証、任意暗号化、弱いパスワード警告
- 個別復元を含む最新PE媒体でのVM／実機検証

### 起動修復・救出

- 複数Windows／曖昧ESPの選択、ESP／システム領域新設
- 第三者EFIローダーの保持／削除選択、このPC向けだけのNVRAM限定修復
- WinREの新規構成／修復（現在のGPT／UEFI経路は登録済みWinREが一意な場合だけ開始）
- 救出モードの有限前後／小ブロック再試行、欠損Map、`一部欠損`結果表示
- 救出時の縮小・形式変換禁止

## PE固有の安全条件

- コピー元をread-only化できない場合は開始しない。
- PE自身が起動したUSBディスク全体を、クローン・復元・救出の対象にしない。
- 起動USBのデータ領域だけをイメージ／ログ保存先として許可する。
- コピー元とEXE／ログ／Checkpoint保存先が同じ物理ディスクにならないようにする。
- ディスク番号、ドライブ文字、表示順だけで対象を解決しない。
- USB筐体の切断後は計画と確認を無効化し、再選択を要求する。
- 最終メタデータ確定中は取消不可と理由を表示する。

## UI検証

2026-08-10の現行binaryでは、イメージ復元ページを1280×720と1024×600の実windowで
表示し、未割当を含む復元先ラベル、主要control、compact sidebarに文字重なり・window外
はみ出しがないことを確認した。イメージ選択後の全操作、DPI、キーボード完走は別途必要。

- 1280×720、1024×600、125～200% DPI
- Tab／Shift+Tab、Enter、Space、Esc、見えるFocus
- 日本語の長文、エラー詳細、ファイル選択、暗号化入力
- Legacy BIOS、UEFI、Secure Boot 2011 CA／2023 CA
- 合成GPT／MBR、通常／縮小、MBR→GPT、データ専用、破損、取消

VMはNIC無効で1台ずつ使用し、新規合成ディスクだけを書込み対象にする。過去のPE
媒体・起動・旧製品経路のPASSは媒体基盤やエンジン部品の根拠として保持し、最新の
直接メニューを収録したISOで再実行するまでv2合格には数えない。
