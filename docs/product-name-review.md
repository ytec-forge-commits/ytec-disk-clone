# 製品表示名

## 採用する開発中名称

- 表示名: `Y-TEC Tsumugi Drive`
- 読み: ワイテック・ツムギ・ドライブ
- 内部識別子: `ytec-disk-clone`を継続
- 状態: 2026-07-31に開発上の正式名称として確定

`Tsumugi`には、元のWindows環境、ディスク上のデータ、起動情報を安全に
つなぎ直す「紡ぐ」という意味を持たせる。製品表示では識別力と混同回避の
ため、`Tsumugi`または`Tsumugi Drive`単独ではなく、原則として
`Y-TEC Tsumugi Drive`の一体表記を使用する。

## 2026-07-31の一次調査

一般Web検索とJ-PlatPatの商標簡易検索を確認した。

- `Y-TEC Tsumugi Drive`はJ-PlatPat商標簡易検索で0件
- `Tsumugi Drive`はJ-PlatPat商標簡易検索で0件
- `ツムギドライブ`はJ-PlatPat商標簡易検索で0件
- 一般Web検索で同一名称のディスククローン、バックアップ、起動修復製品は
  確認できなかった
- `TSUMUGI`または`つむぎ`単独は、アプリ、業務ソフト、団体名など別分野で
  広く使用されている

以上から開発上の正式名称として採用する。ただし、この調査は非網羅的な
一次スクリーニングであり、商標上の非侵害や登録可能性を保証しない。
一般公開、販売、商標出願の前に、日本の第9類・第42類を中心として、
称呼・外観・観念と指定商品役務を含む弁理士等の類否調査を行う。
